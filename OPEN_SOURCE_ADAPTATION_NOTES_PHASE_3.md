## Final local destinations and validation

- `backend/services/resource_normalization.py`: original bounded NFKC/casefold normalization; display text retained. Bounds apply after compatibility expansion too.
- `backend/services/resource_channels.py`: local SQLAlchemy channels using PostgreSQL's public FTS/trigram APIs. `simple` + `plainto_tsquery` treats identity-probe tokens literally. Whole similarity plus strict word similarity; indexed `%` and `%>>`, with no GiST/KNN path. Actual server semantics/plans remain pending.
- `backend/services/resource_discovery.py`: RapidFuzz library calls on the bounded candidate union, channel provenance and independent conservative resolution. Token-set 100 is not by itself identity proof.
- `backend/services/hybrid_retrieval.py::weighted_rank_union`: original generalized local one-based formula; existing chunk `weighted_rrf` is unchanged. No upstream framework class copied.
- `backend/database/resource_schema_v1.py` and `backend/migrations/versions/20260912_01_resource_catalog.py`: local tenant-safe relational/trigger/index design, not copied upstream DDL.
- `backend/services/resource_scope_adapter.py`: local handoff to the unchanged Phase 2.5 scope policy, not an upstream model/router integration.
- `backend/scripts/test_phase3_postgres.py`: extends the repository's Docker-only ownership pattern without changing the Phase 2 harness or enabling remote selection.

Final policy `conservative-evidence-4`: exact weight 2; FTS/trigram 1; metadata/legacy/deferred dense 0.5; RRF k=60. Token specificity/corroboration and ambiguity checks gate resolution separately. Final freeze: 2026-09-12T11:40:25.7151582Z, before the final 168-case held-out and historical runs. The 444 development and 168 held-out references pass all offline gates; this does not validate actual PostgreSQL trigram scores/index use.

RapidFuzz 3.14.6 was installed with `--no-deps` into the existing local backend virtual environment and pinned in the existing requirements file. No LlamaIndex, RAGFlow, Onyx or other large framework was installed; no global/system environment changed. No resource embedding/model call was added. No additional license/NOTICE obligation from copied substantial source arises because none was copied; the installed RapidFuzz distribution retains its MIT license.
