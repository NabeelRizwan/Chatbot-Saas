## Port rules

1. Normal retrieval remains pinned at 0.2 and 0.7/0.3 with unchanged models/budgets. Advanced BM25-only or vector-only tools retain their actual upstream tool semantics, not disguised changes to normal retrieval.
2. Actual native tool calls, LangGraph transitions, compiler outputs and persistent lineage are required before a mode is labelled supported. Deterministic doubles prove parity, not live quality.
3. Tenant/bot/version/generation/READY validation happens before storage access and after results. Model IDs can only narrow an already authorized set. Generated summaries/graphs are explicitly derived artifacts.
4. Existing unrelated uncommitted work and prior reports are preserved. No customer/production access. No quality datasets during porting. No new GPU/paid service without authorization.
5. Each copied/adapted source must have pin/blob/destination hashes and Apache attribution. Unsupported product-bound features fail explicitly; they do not fall through to an apparently successful normal-mode result.
